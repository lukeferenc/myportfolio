Aestra

Python · FastAPI · CycleBench · Model-pFL · optional OpenAI phrasing

Repo

Chip-based intake that turns cycle timing and symptoms into an appointment-ready soft read. Underneath sits CycleBench — schema, deterministic engine, audit, open NHANES export, and a personalized phase model — so the LLM only phrases language and never invents findings. Built for the Hack-Nation women’s hormonal health challenge.
